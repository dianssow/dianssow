## Projekte

###  KI-Verkaufs- und Support-Agent
Autonomer Agent mit **Model Context Protocol (MCP)** und lokalen Ollama-Modellen (Qwen2.5, nomic-embed-text), mehrsprachig (DE/EN/FR).

- **Hybrid-Suche** mit PostgreSQL: pgvector (semantisch) + Volltextsuche, Fusion per **Reciprocal Rank Fusion (RRF)**
- **MCP-Tools** für Produktabfrage, Alternativvorschläge und Bestellungen mit menschlicher Bestätigung
- **Bestandsreduzierung und Audit-Log** über PostgreSQL-Trigger
- **Eingabe-Guardrail** gegen unzulässige Anfragen

`Python` `PostgreSQL` `pgvector` `Ollama` `MCP` 

[Repository ansehen :](https://github.com/dianssow/ai-agent)

- Backend mit **Node.js/Express und Firebase Firestore**
- Multi-Tenant-Architektur mit rollenbasierten Berechtigungen

`React` `Redux Toolkit` `Node.js` `Express` `Firebase`
